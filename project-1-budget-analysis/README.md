# 📊 تقرير الميزانية المالية للأقسام

**المشروع**: تحليل إجمالي الرواتب والمتوسطات لكل قسم في الشركة  
**التاريخ**: 21 يوليو 2026  
**المحلل**: ياسين المحمد

---

## 📌 الهدف من المشروع
يهدف هذا التقرير إلى تقديم نظرة شاملة على هيكل التكاليف المالية لكل قسم، من خلال عرض:
- عدد الموظفين في كل قسم.
- إجمالي الرواتب الشهرية.
- الحد الأدنى والأعلى للأجور.
- متوسط الرواتب.

يساعد هذا التحليل الإدارة في تحديد الأقسام الأكثر استهلاكاً للميزانية، واتخاذ قرارات إعادة الهيكلة أو التوسع.

---

## 🛠️ الأدوات والتقنيات المستخدمة
- **قاعدة البيانات**: Oracle 21c XE
- **بيئة التطوير**: SQL Developer
- **اللغة**: SQL
- **المفاهيم**: `JOIN`، `GROUP BY`، دوال التجميع (`SUM`, `AVG`, `MIN`, `MAX`)

---

## 📂 محتويات المشروع
- `budget_report.sql` - استعلام SQL المستخدم لاستخراج البيانات.
- `budget_report.pdf` - التقرير النهائي بصيغة PDF (جاهز للتسليم).

---

## 🔍 أبرز النتائج
- **أعلى قسم من حيث إجمالي الرواتب**: `Sales` (304,500 $).
- **أعلى قسم من حيث متوسط الرواتب**: `Executive` (16,225 $).
- **أكبر قسم من حيث عدد الموظفين**: `Shipping` (45 موظفاً).

---

## 🚀 كيفية تشغيل الاستعلام
1. افتح SQL Developer واتصل بقاعدة بيانات Oracle.
2. انسخ محتوى ملف `budget_report.sql`.
3. شغّل الاستعلام، وستحصل على النتائج مباشرة.
