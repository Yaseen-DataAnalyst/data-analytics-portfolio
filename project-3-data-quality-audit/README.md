# 🔍 تقرير تدقيق جودة البيانات (Data Quality Audit)

**المشروع**: تدقيق شامل لقاعدة بيانات الموظفين للكشف عن الأخطاء والتكرارات  
**التاريخ**: 21 يوليو 2026  
**المحلل**: ياسين المحمد

---

## 📌 الهدف من المشروع
يهدف هذا التقرير إلى التحقق من سلامة وجودة البيانات قبل البدء بأي تحليل إحصائي، من خلال فحص أربعة محاور رئيسية:
1. **التكرارات**: التأكد من عدم وجود موظفين مكررين.
2. **القيم المتطرفة (الشاذة)**: الكشف عن الرواتب غير المنطقية.
3. **التواريخ غير المنطقية**: التأكد من أن تواريخ التوظيف صحيحة.
4. **العلاقات الإدارية**: التأكد من أن جميع الموظفين لديهم مدير معروف.

---

## 🛠️ الأدوات والتقنيات المستخدمة
- **قاعدة البيانات**: Oracle 21c XE
- **بيئة التطوير**: SQL Developer
- **اللغة**: SQL
- **المفاهيم**: البحث عن `NULL`، الكشف عن التكرارات (`HAVING COUNT(*) > 1`)، الكشف عن القيم الشاذة (`Outliers`).

---

## 📂 محتويات المشروع
- `audit_report.sql` - استعلامات SQL المستخدمة لتدقيق البيانات.
- `audit_report.pdf` - التقرير النهائي بصيغة PDF (جاهز للتسليم).

## 🔍 نتائج التدقيق
| نوع الفحص | عدد الأخطاء المكتشفة | الحالة |
| :--- | :---: | :---: |
| فحص التكرارات | 0 | ✅ سليم |
| فحص القيم المتطرفة (الشاذة) | 0 | ✅ سليم |
| فحص التواريخ غير المنطقية | 0 | ✅ سليم |
| فحص العلاقات الإدارية | 0 | ✅ سليم |

**الخلاصة**: قاعدة البيانات خالية تماماً من الأخطاء (نقاء 100%)، وجاهزة للتحليل الفوري.

---

## 🚀 كيفية تشغيل الاستعلامات
1. افتح SQL Developer واتصل بقاعدة بيانات Oracle.
2. انسخ محتوى ملف `audit_report.sql`.
3. شغّل كل استعلام على حدة، وستحصل على النتائج مباشرة.
