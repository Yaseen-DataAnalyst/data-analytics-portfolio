# 📊 تحليل مبيعات المناطق والمنتجات

**المشروع**: تحليل بيانات مبيعات شركة متعددة المناطق.  
**التاريخ**: 25 يوليو 2026  
**المحلل**: ياسين المحمد

---

## 📌 الهدف من المشروع
تحليل بيانات مبيعات شركة تعمل في عدة مناطق، للإجابة على ثلاثة أسئلة رئيسية:
1. ما هي إجمالي المبيعات لكل منطقة (مرتبة تنازلياً)؟
2. ما هو المنتج الأكثر مبيعاً (من حيث عدد الوحدات) في كل منطقة؟
3. من هو أفضل مندوب مبيعات على مستوى الشركة؟

---

## 🛠️ الأدوات والتقنيات المستخدمة
- **قاعدة البيانات**: Oracle 21c XE
- **بيئة التطوير**: SQL Developer
- **اللغة**: SQL
- **المفاهيم**: `GROUP BY`، `SUM`، `ORDER BY`، دوال التجميع

---

## 📂 محتويات المشروع
- `sales_analysis.sql` - استعلامات SQL الثلاثة.
- `sales_report_region.pdf` - تقرير إجمالي المبيعات حسب المنطقة.
- `sales_report_product.pdf` - تقرير أفضل منتج في كل منطقة.
- `sales_report_salesperson.pdf` - تقرير ترتيب مندوبي المبيعات.

---

## 🔍 أبرز النتائج
- **أفضل منطقة من حيث إجمالي المبيعات**: `North` (967,957.98$).
- **أفضل منتج مبيعاً (من حيث الكمية)**: `Tablet` في منطقة West (636 وحدة).
- **أفضل مندوب مبيعات**: `Bob` (796,780.52$).

---

## 🚀 كيفية تشغيل الاستعلامات
1. استورد ملف البيانات إلى SQL Developer.
2. شغّل الاستعلامات في `sales_analysis.sql`.
3. ستظهر النتائج مباشرة.
