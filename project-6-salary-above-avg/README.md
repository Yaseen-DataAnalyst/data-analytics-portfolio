# 📊 التحقق من راتب الموظف مقابل متوسط قسمه

**المشروع**: تحديد ما إذا كان راتب كل موظف أعلى من متوسط رواتب قسمه أم لا.  
**التاريخ**: أغسطس 2026  
**المحلل**: ياسين المحمد

---

## 📌 الهدف
استخدام دالة `AVG()` مع `OVER` و `PARTITION BY` لحساب متوسط راتب كل قسم، ثم مقارنة راتب كل موظف بمتوسط قسمه باستخدام `CASE`.

---

## 🛠️ الأدوات والتقنيات
- **قاعدة البيانات**: Oracle 21c XE
- **بيئة التطوير**: SQL Developer
- **اللغة**: SQL
- **المفاهيم**: `AVG() OVER(PARTITION BY)`، `CASE`، `CTE` (WITH)

---

## 📂 محتويات المشروع
- `salary_above_avg.sql` - استعلام SQL للتحقق من الرواتب مقابل متوسط القسم.
- `salary_above_avg_report.pdf` - نتائج الاستعلام على شكل جدول.

---

## 🔍 أبرز النتائج
- يميز الاستعلام الموظفين الذين يتقاضون رواتب أعلى من متوسط أقسامهم (`YES`) ومن هم أقل أو يساوي المتوسط (`NO`).
- يساعد هذا التحليل إدارة الموارد البشرية في اكتشاف التفاوت في الرواتب داخل الأقسام.

---

## 🚀 كيفية تشغيل الاستعلام

2. انسخ محتوى ملف `salary_above_avg.sql`.
